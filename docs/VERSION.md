# バージョン履歴

`package.json` の `version` と同期する。git コミットのたびにこのファイルを更新する（規約: `.cursor/rules/version-changelog-on-commit.mdc`）。

## 0.0.13 (2026-08-08)

- X投稿「Xへ投稿」ボタンの Server Action エラーを画面に表示するよう修正
- 操作ボタン行のレイアウト調整

## 0.0.12 (2026-08-08)

- スプレッドシートの既存列名（日付・投稿内容・備考など）へ正しくマッピングして転記

## 0.0.11 (2026-08-08)

- スプレッドシート同期時、1行目に ID 列が無い場合は A 列へ自動挿入するよう修正
