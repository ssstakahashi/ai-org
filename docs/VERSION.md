# バージョン履歴

`package.json` の `version` と同期する。git コミットのたびにこのファイルを更新する（規約: `.cursor/rules/version-changelog-on-commit.mdc`）。

## 0.0.28 (2026-08-14)

- X投稿スケジュール一覧を予約日時の昇順で表示
- X投稿の画像解析を Gemini API ベースに刷新（タイトル・本文を同時生成）
- 画像解析中のローディング表示と音声入力の操作性を改善

## 0.0.27 (2026-08-14)

- 業務台帳タスク登録・編集に Workers AI（Whisper）による音声文字起こしを追加
- ローカル開発では Workers AI REST API（CF_API_TOKEN）を利用するよう対応
- X 投稿フォームで画像選択時に AI が投稿文を提案
- タスク詳細の削除を確認ダイアログに変更、編集ダイアログをドック形式に統一
- 本番ビルド時に initOpenNextCloudflareForDev を実行しないよう修正（deploy 失敗の解消）
- deploy.sh で Cloudflare Access 非対話環境でも wrangler deploy できるよう変更
