# バージョン履歴

`package.json` の `version` と同期する。git コミットのたびにこのファイルを更新する（規約: `.cursor/rules/version-changelog-on-commit.mdc`）。

## 0.0.7 (2026-08-08)

- X投稿スケジュールの新規作成に「下書き」「完了」ステータスを追加し、デフォルトを下書きに変更

## 0.0.6 (2026-08-08)

- 従業員の新規登録をダイアログ入力に変更
- 従業員カードに編集ボタンを追加
- 従業員カード上から色を直接設定できるようにした

## 0.0.5 (2026-08-08)

- 新規タスクに「下書き」ステータスを追加し、デフォルトを下書きに変更
- 下書きタスクはカレンダー・ガントに載せず、日付未定リストに表示

## 0.0.4 (2026-08-08)

- カレンダー・ガントの「今日」セル背景を黄色（#fff9c4）に変更

## 0.0.3 (2026-08-08)

- タスク詳細の完了・編集・削除ボタンにアイコンを追加し角丸を統一
- 削除ボタンを赤背景に変更
- カレンダーの土日セルに背景色を追加

## 0.0.2 (2026-08-08)

- バージョン表示を git タグ（v なし）優先、未タグ時は package.json に変更
- タスク詳細パネルから削除できるように追加

## 0.0.1 (2026-08-08)

- ナビに git describe 由来のバージョン表示を追加
- 完了タスクに取り消し線を表示（カレンダー・ガント）
- タスク詳細→編集ダイアログ切替の不具合を flushSync で修正
